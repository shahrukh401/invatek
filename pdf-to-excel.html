About PDF to Excel

PDF to Excel reads the text on each page and arranges it into rows and cells, so a table in your PDF becomes a table in Excel. It also reads scanned PDFs and photos using OCR, which turns pictures of text into real text.

Choose the language of the text, English, Hindi or both, before you start. Check the result in Excel afterwards, because tables with complex layouts may need a little tidying.

How to use it

  1. Open the tool and add a PDF or a photo.
  2. Choose the language of the text.
  3. Tap the convert button. Scans can take a minute.
  4. Save the Excel file and open it to check the cells.

Tips

  • Clear, straight, well lit scans give the best results.
  • OCR is not perfect. Always check numbers before you use them.
  • Pick Hindi and English together if the page has both.

Questions

Does it work on scanned PDFs?

Yes. It uses OCR for pages that have no selectable text.

Why are some cells wrong?

OCR can misread blurry or small text. Rescan in better light to improve it.

Is my file uploaded?

No. The reading is done in your browser. The first time, the language data is downloaded.
