About Photos to PDF

Photos to PDF is handy for sending ID proofs, receipts or handwritten notes as a single file. Each photo gets its own A4 page and is kept in proportion.

Add the photos, set the order with the arrows, and create the PDF. If you want the pages cleaned up and cropped, use the Scan to PDF tool instead.

How to use it

  1. Open the tool and tap Choose files. Select your photos.
  2. Put them in order using the up and down arrows.
  3. Tap Create PDF.
  4. Save the file or share it.

Tips

  • Take photos in good light and hold the phone straight.
  • Large photos make a large PDF. Check the size before you upload it somewhere.
  • Use Scan to PDF if you want shadows removed and the page cropped.

Questions

Which photo types work?

JPG, PNG and WebP.

Is the order kept?

Yes. Pages follow the order shown in the list.

Is my photo uploaded?

No. The PDF is made in your browser.
