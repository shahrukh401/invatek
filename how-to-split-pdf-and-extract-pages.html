How to split a PDF and extract pages

Sometimes you need only page 3 of a 40 page file. Splitting gives you just that.

All toolsArticlesGuidesAboutPrivacyContact

Updated 11 November 2026

Two ways to split

  • Extract chosen pages: you type the pages and get one new PDF with only those pages.
  • Save every page separately: you get a ZIP file with one PDF per page.

How to write page numbers

Use commas for single pages and a dash for ranges. For example 1-3, 5, 8- means pages 1, 2, 3, then 5, then page 8 to the end of the file. The tool shows the total page count so you do not guess.

Steps

  1. Open Split PDF and choose your file.
  2. Choose Extract chosen pages or Save every page as a separate PDF.
  3. Type the pages if you chose the first option.
  4. Tap the button and save the result.

Common uses

  • Send only the signed page of a contract.
  • Share one chapter of a long study material.
  • Keep the ID page from a large scanned bundle.
  • Cut a big report into parts that fit an email.

Questions

Is my original changed?

No. You always get new files.

What is inside the ZIP?

One PDF for every page. Open the ZIP in your Files app.
