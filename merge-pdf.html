About Merge PDF

Merging PDFs means joining several files into one. People do it to send one attachment instead of five, to combine scanned pages, or to put an application together in the right order.

Add your files, move them up or down until the order is right, and merge. The first file becomes the first pages of the new PDF. The original files are never changed.

How to use it

  1. Open the tool and tap Choose files. Select two or more PDFs.
  2. Use the up and down arrows to set the order.
  3. Tap Merge PDFs.
  4. Tap Save file, or Share to send it straight to WhatsApp or email.

Tips

  • Rotate any sideways page first with the Rotate PDF tool, then merge.
  • Scanned files are large, so the merged file can be large too. Check the size before you upload it to a form.
  • Remove a file from the list with the cross button if you added it by mistake.

Questions

Are my files uploaded?

No. The merge happens inside your browser.

Can I merge a password protected PDF?

Not yet. Remove the password in the app that made it, then merge.

How many files can I merge?

There is no set limit, but very large files may be slow on older phones.
