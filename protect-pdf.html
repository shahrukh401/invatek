About Protect PDF

Protect PDF puts a password on your file. Anyone who wants to open it must type the password first. This is useful for bank statements, ID proofs, resumes and any document you send over WhatsApp or email.

The lock uses AES 256 encryption, the same strong method used by modern PDF software. It works in Chrome, Safari, Edge and Firefox on phones and computers. Your original file is not changed, you get a new protected copy.

How to use it

  1. Open the tool and add your PDF.
  2. Type a password, then type it again to confirm. Tap Show password if you want to check it.
  3. Tap Protect PDF.
  4. Tap Save file, or Share to send it. The person who receives it will be asked for the password.

Tips

  • Use at least 8 characters with letters and numbers, so the password is hard to guess.
  • Share the password in a different way from the file, for example by phone call.
  • Write the password down somewhere safe. A lost password cannot be recovered by us or anyone else.
  • Old PDF readers may not support AES 256. Chrome, Edge, Safari, Firefox and current Adobe Reader do.

Questions

Is my file or password uploaded?

No. The file is locked inside your browser and nothing is sent to a server.

Can I remove the password later?

This tool only adds a password. To remove it you need the password and a PDF app that can unlock files.

Why can I not preview the protected file here?

The preview cannot open a locked file without the password. Save it and open it in any PDF reader to test it.
