About Compress PDF

Large PDFs are hard to send and often rejected by websites that limit file size. Most of the weight comes from pictures, especially scans and phone photos. This tool redraws each page at a smaller size and quality, then builds a lighter PDF.

Balanced is the best starting point. Strong makes the smallest file but turns pages into pictures, so the text cannot be selected afterwards. Light keeps the text as text and saves only a little. If a file cannot be made smaller, the tool tells you and returns your original.

How to use it

  1. Open the tool and add your PDF. Its size is shown.
  2. Choose Balanced, Strong or Light.
  3. Tap Compress PDF. Large files can take a little while.
  4. Check the new size, then tap Save file. Open it once to confirm it is readable.

Tips

  • Compress from your original file, not from an already compressed copy.
  • Use Strong only when a form has a strict size limit.
  • Scans in black and white give much smaller files than colour scans.
  • Always zoom in on names and numbers in the result before you send it.

Questions

Is my file uploaded?

No. The PDF is compressed inside your browser and never leaves your device.

Why can I not select text after compressing?

Balanced and Strong turn each page into a picture to save space. Use Light if you need to keep the text.

What if the file does not get smaller?

Some PDFs are already well compressed. The tool then returns your original and says so.
