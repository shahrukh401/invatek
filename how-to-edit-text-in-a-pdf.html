How to edit text in a PDF

Found a typo in a PDF? You can fix it on your phone in a minute, as long as you know how PDF editing really works.

Updated 11 November 2026

Why PDFs are hard to edit

A PDF is built to look the same everywhere, not to be changed. Unlike a Word file, it does not store paragraphs that flow and reflow. Each piece of text sits at a fixed place on the page. That is why simple editors cannot just let you type in the middle of a line.

How Change text works

Invatek finds the lines of text on the page and highlights them. When you tap one and type new words, the tool covers the old line with a box in the page colour and places your new text in the same spot, at the same size and colour. The result looks like an edited line.

Steps

  1. Open Edit PDF and choose your file.
  2. Pick Change text. Lines you can edit are marked in blue.
  3. Tap a line, type the new text, then tap outside the box.
  4. Move it a little with the Move tool if needed.
  5. Tap Save edited PDF and check the page.

What to expect

  • Fonts: your text uses a standard font, so bold or decorative fonts will look slightly different.
  • The old text stays hidden inside the file. Anyone who selects text may still find it, so never use this to hide private details.
  • Scanned pages are pictures, so lines cannot be picked. Use the Text and Whiteout tools there.
  • For bigger rewrites, convert the PDF to Word with PDF to Word, edit it, and save it again as a PDF.

Questions

Can I edit a scanned PDF?

Not with Change text. You can cover and write over it with Whiteout and Text, or convert it to Word using OCR.

Will the layout break?

Only the line you change is affected. If your new text is longer, it may run over nearby items, so check the page.
