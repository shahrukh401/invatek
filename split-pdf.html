About Split PDF

Splitting a PDF helps when a form asks for only one page of a long document, or when you want to share part of a file and not all of it.

You can type the pages you want, like 1-3, 5, 8-, and get one new PDF with just those pages. Or choose to save every page as its own PDF inside a ZIP file.

How to use it

  1. Open the tool and add your PDF. The page count appears under the file name.
  2. Choose Extract chosen pages, or Save every page as a separate PDF.
  3. For extracting, type the pages, for example 1-3, 5, 8-.
  4. Tap the button and save the result.

Tips

  • 1-3 gives pages 1, 2 and 3. 5- gives page 5 to the end.
  • The original file is never changed. You get a new file.
  • A ZIP file must be opened before you can use the pages. Most phones can open it in the Files app.

Questions

Can I split into two halves?

Yes. Run the tool twice, for example 1-5 and then 6- for a 10 page file.

Why does it say pages must be between 1 and a number?

You typed a page number the file does not have. The real page count is shown above the box.

Is the quality reduced?

No. The pages are copied as they are.
