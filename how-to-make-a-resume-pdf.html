How to make a resume PDF that looks professional

Recruiters often open resumes on phones. A tidy PDF makes a better first impression than a Word file that shifts.

Updated 11 November 2026

Start with a simple layout

  • Use one common font and a size between 10 and 12 for body text.
  • Keep to one or two pages.
  • Use clear headings: Summary, Experience, Education, Skills.
  • Avoid heavy tables and text boxes, which can break when converted.

Convert to PDF

  1. Save your resume as a .docx file.
  2. Open Word to PDF on Invatek and choose it.
  3. Tap Convert to PDF and save the file.
  4. Open the PDF and check every page on your phone.

Name and size

Give the file a clear name such as FirstName-LastName-Resume.pdf. Avoid names like final-final2. Most job portals accept files up to a few MB. If yours is larger, use Compress PDF.

Final checks

  • Read it once for spelling and phone number mistakes.
  • Make sure links, if any, are written in full.
  • Do not add private details such as your full ID number.
  • Keep the original Word file so you can edit it later.

Questions

Should I send Word or PDF?

PDF, unless the employer asks for Word. It keeps the layout fixed.

Can I write the resume in Hindi?

Use Text to PDF for Hindi text, since it draws Hindi letters correctly.
