Reduce PDF size for online forms and uploads

Many application portals only accept small files. This guide shows how to get your PDF under the limit without starting over.

Updated 11 November 2026

First, check the limit

Every form states a maximum size, often shown in KB or MB. Note it before you begin. 1 MB is 1024 KB, so a 200 KB limit is much stricter than a 2 MB limit.

Also check the file type. Some forms want a PDF, others only accept JPG. If a PDF is needed, make sure you upload a PDF and not a renamed photo.

A simple plan

  1. Put all pages in one file with Merge PDF or Photos to PDF if the form wants a single document.
  2. Open Compress PDF and try Balanced. Check the new size shown in the result.
  3. If it is still too big, run the original again with Strong.
  4. Open the saved file and check that the text and numbers are readable before you upload.

If it is still too large

  • Remove pages you do not need with Remove pages.
  • Scan again with Scan to PDF using Black and white, which is often much smaller for printed text.
  • Take photos in good light. Dark, noisy photos compress badly and give large files.
  • Split a very long file and upload it in two parts if the form allows it.

Do not make it unreadable

A file that is small but blurry will be rejected by a reviewer. After compressing, zoom in on the most important lines such as names, numbers and dates. If they are hard to read, go back one level.

Questions

Is it safe to compress ID documents here?

The work happens in your browser and nothing is uploaded, but still keep your own backup.

Will the form accept the result?

If it is a normal PDF under the size limit, yes. Rules differ by website, so read the instructions on the form.
