How to send a large PDF on WhatsApp and email

Messaging apps and email services limit file size. Here is how to get a big PDF through.

All toolsArticlesGuidesAboutPrivacyContact

Updated 11 November 2026

Why sending fails

Email providers cap attachment size, and chat apps cap document size too. Limits change from time to time, so check the current limit of your app. A scan of ten pages can already be bigger than a typical email limit.

Option 1: make it smaller

  1. Open Compress PDF and choose your file.
  2. Start with Balanced and check the size shown.
  3. If it is still big, use Strong.
  4. Send the new file.

Option 2: send in parts

Use Split PDF to cut the file into parts, for example pages 1-10 and 11-20, and send each part in a separate message. Name them clearly, such as Part 1 of 2.

Option 3: reduce what you scan

  • Scan in Black and white for text pages.
  • Remove pages that are not needed.
  • Use fewer, clearer photos instead of many duplicates.

Protect private files

If you send ID proofs or financial papers, add a password with Protect PDF and tell the receiver the password by phone call.

Questions

Does WhatsApp compress PDFs?

Documents are sent as files, so they are not reduced like photos. Make the file smaller yourself first.

Should I share a link instead?

For very large files, a cloud storage link can be easier. Make sure only the right people can open it.
