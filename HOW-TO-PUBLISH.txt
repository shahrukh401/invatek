Invatek upload steps
1. GitHub repo me "Add file" > "Upload files" se is zip ki SAARI files ek saath upload karo (zip khol kar).
2. ".github" folder (static.yml) KABHI delete mat karna.
3. Ab app.js / app.css ki zaroorat nahi, har page me sab andar hi hai. GitHub par purani app.js, app.css ho to delete kar sakte ho.
4. Deploy ke baad (Actions me hara tick) site ko Ctrl+Shift+R se ya browser cache clear karke kholo.
5. Search Console me sitemap.xml dobara submit karo.
