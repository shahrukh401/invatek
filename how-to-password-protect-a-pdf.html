How to password protect a PDF

Some papers are private: bank statements, ID copies, salary slips. A password makes sure only the right person can open them.

What a PDF password does

When you add a password, the content of the PDF is encrypted. Without the password, a reader cannot see the pages. Invatek uses AES 256, a strong modern method supported by Chrome, Safari, Edge, Firefox and current Adobe Reader.

Steps

  1. Open the Protect PDF tool and add your file.
  2. Type a password and type it again to confirm.
  3. Tap Protect PDF.
  4. Save the new file and test it by opening it in a PDF reader.

Choosing a good password

  • Use at least 8 characters, mixing letters and numbers.
  • Avoid names, birthdays and phone numbers that others can guess.
  • Share the password separately, for example by phone call, never in the same chat as the file.
  • Write it down somewhere safe. A lost password cannot be recovered.

Good to know

Your original file stays unlocked, so keep it safe too. The protected copy is a new file. Because the lock happens in your browser, neither the file nor the password is sent to Invatek or anyone else.

Questions

Can I remove the password later?

This tool only adds a password. Removing one needs the password and a PDF app that can unlock files.

Does it work on all phones?

Modern phones and browsers open AES 256 files. Very old readers may not.
